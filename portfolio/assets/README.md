# assets/

Ce dossier est destiné à contenir :
- Captures d'écran de vos projets (ex: screenshot-flask-app.png)
- Votre CV en PDF (cv.pdf)
- Toute autre image ou ressource statique

## Organisation suggérée

assets/
├── cv.pdf                    ← votre CV téléchargeable
├── screenshot-flask.png      ← capture du projet Flask/React
├── screenshot-ml.png         ← capture du dashboard ML
└── screenshot-frontend.png   ← capture du site HTML/CSS/JS

## Utilisation dans le HTML

Pour ajouter une vraie image dans une project-card, remplacez l'emoji par :
<img src="assets/screenshot-flask.png" alt="Aperçu" style="width:100%; height:100%; object-fit:cover;" />
